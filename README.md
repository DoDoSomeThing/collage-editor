# 拼圖編輯器 Collage Editor

自由格數、自由縮放、自己上傳照片的拼圖工具。輸出限時動態 / 貼文尺寸 PNG。

**線上使用:** https://jx0876.github.io/collage-editor/

## 功能

- 上傳自己的照片(選檔或拖曳進頁面)
- 任意數量格子:拖曳移動、角落縮放、複製、刪除、置前置後、一鍵平均鋪滿
- 每格:滾輪縮放圖、Shift 拖移圖內位置、方形/圓形、白框開關
- 全域:背景色、圓角、白框顏色與粗細
- 比例:9:16 / 4:5 / 1:1 / 16:9 / 3:4
- 匯出原尺寸 PNG
- 移動時自動吸邊/置中對齊輔助線

## 技術

單一 HTML 檔,canvas 渲染,零相依、純前端、離線可用。照片只在瀏覽器記憶體處理,不會上傳到任何伺服器。
